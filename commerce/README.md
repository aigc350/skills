# Commerce 电商板块

> 作者主页: [github.com/aigc350/skills](https://github.com/aigc350/skills)

电商运营、商品数据、选品分析等场景的 Skill 集合。

## Skill 速览

| Skill | 适用场景 |
|---|---|
| **[commerce_selection/](commerce_selection/)** | 想系统化做跨境选品判断，不想只凭榜单和直觉 |
| **[kalodata/](kalodata/)** | 想快速查 TikTok Shop 商品 / 达人 / 店铺 / 视频的销量和趋势 |

## 选品 ↔ 数据 的常见路径

```
kalodata (查 TikTok Shop 数据)
        ↓
commerce_selection (套用 SOP 做选品判断)
        ↓
         候选商品 + 评分 + 淘汰原因 + 下一步动作
```
